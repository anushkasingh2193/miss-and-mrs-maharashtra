# Winners Hero Split Design

## Goal

Replace the crowded Winners hero with a clear editorial composition that keeps the existing visual identity and makes the titleholders the focal point.

## Approved direction

- Use a two-column hero on desktop: a compact title block on the left and one clean lineup photograph on the right.
- Keep the “Hall of Fame” eyebrow and “Winners Gallery” title, but never place text over contestants.
- Remove the duplicated background photograph, oversized inset frame, decorative side rules, and heavy bottom title overlay.
- Show the existing 3:2 lineup image without unnecessary cropping so faces, crowns, and sashes remain visible.
- Stack the title block above the photograph on smaller screens.
- Preserve the navy, ivory, and gold page palette and the existing Winners category and season controls below the hero.

## Layout and behavior

- Desktop: balanced editorial grid with the text column supporting the larger image column.
- Mobile: natural document order—label, title, supporting copy, then image.
- Maintain strong separation from the navigation and Winners archive using existing gold dividers.
- Keep the hero responsive without fixed-position overlays or duplicate imagery.

## Accessibility and verification

- Retain meaningful alternative text for the lineup photograph.
- Keep semantic heading order and sufficient text contrast.
- Verify the hero at mobile and desktop widths, run the Winners regression test, and run a production build before deployment.
